# V3.4 엔진 관측 기록

갱신: 2026-07-23. V3.3의 관문+로보 후속 확장 정체를 고친 뒤의
독립 엔진 재검증이다. 원본 JSON은 `runtime/reports/v3.4-*.json`에 남긴다.

## 변경

후속 확장의 일꾼 포화 판정만 V3의 수동 spot 산식에서 upstream native
`AIGetMinPeonCount(player, c_townMax)`로 변경했다. 생산용 일꾼 상한과
`AISetStockExpand`/`AIExpand` town claim 흐름은 바꾸지 않았다.
