# V3.3 엔진 관측 기록

갱신: 2026-07-23. 모든 값은 SC2 5.0.16.97425에서 빌드별 단독
옵저버 하네스로 180초 간격으로 수집했다. 원본 JSON은 실행별로
`runtime/reports/v3-*.json`에 남긴다.

## V3.3 변경

- town-local 생산 bootstrap을 `AISetStockEx(mainTown, 1, ...)`으로
  등록했다. 아직 Established 확장이 없을 때 미래 확장 몫은 등록하지 않는다.
- 관문/메카닉은 Blizzard opening과 같은 기본 병력 체크포인트를 만족한 뒤
  시간 단계의 고급 테크로 전환한다.
- established town의 실제 가스 지점만 `V3SetExpansionGasPolicy`가
  `AISetStockEx`로 등록한다. 3기지에서 불가능한 전역 12 가스 대기열은 제거했다.
- 포화 후속 확장은 `AISetStockExpand(player, townHall, established + 1)`로
  자원을 stock에 비축하고, 보유 자원이 찼을 때 `AIExpand`로 town을 claim한다.

## 배치 관측

- 테란 바이오닉 6분: 본진 병영 1개, 첫 확장 병영 2개·공장 1개.
  9분에는 세 번째 established town에 병영/공장이 실제 건설 중이었다.
- 테란 메카닉 6분: 본진 공장 1개, 첫 확장 공장 2개. 12분에는 세 번째
  town에도 공장이 배치됐다.
- 프로토스 관문 6분: 본진 WarpGate 2개, 첫 확장 WarpGate 1개이며
  확장 자원 측 파일런 두 개가 먼저 완료됐다. 12분에는 세 번째 town에도
  파일런과 관문 생산 경로가 생겼다.
- 프로토스 관문+로보 6분: 본진 관문 2개, 첫 확장 로보 1개. 12분에
  첫 확장에 관문/로보가 추가됐다.
- 저그는 확장 Hatchery가 곧 생산 건물이므로 mining town과 별도로 본진
  매크로 Hatchery 목표(총 2/3/5 단계)를 사용한다. 18분 두 저그 빌드에서
  본진 외 macro Hatchery 2개가 실제 존재했다.

## 판정과 남은 항목

- 구조/문법 및 모든 최신 9분 단독 테스트는 PASS다.
- 18분 로그는 여섯 빌드 모두 일꾼·가스·병력·업그레이드의 실제 진행을 보인다.
- 이 작은 시험 맵은 각 단독 run에서 3개의 광물 기지 이후
  `AIHasNearbyOpenExpansion`이 더 이상 true가 되지 않아 6기지 경로를
  관측하지 못했다. 저그의 `c_townMax` 상한은 그대로 남아 있으나, 6기지
  이상 실증은 더 큰 다중 확장 맵에서 별도 실행해야 한다.
