## Read this first

The current deliverable is a Windows-only local StarCraft II launcher for one human and up to thirteen AI slots on a modified 14-player melee map. The stable implementation is `Custom AI v1.25.0`.

The project does **not** run several independent ladder ProBots in one team game. SC2 5.0.16 permits one external API Participant plus multiple built-in Computer players, but rejects multi-agent games beyond 1v1. The current design therefore combines Blizzard's elite melee AI with a local Python strategy controller and a generated Galaxy command bridge. P15 wild Zerg is optional: ON promotes it to an additional lobby Computer at the alpha nest and runs its custom Galaxy controller; OFF leaves it neutral-hostile and harvest-only. The saved user configuration currently has wild Zerg OFF.

The current release artifact is `runtime/maps/europe-melee-custom-ai-v1.25.0.SC2Map`, 3,020,527 bytes, SHA-256 `D8470D9BD22E9831D614CB3DBD30C8761A3047B47BF866093EDE9268A530D832`, rebuilt with the saved user settings (wild_zerg off, unit_control off) and launcher-equivalent flags. ## Current user-facing result

Run:

```bat
start_custom_ai.cmd
```

For manual testing there is a second entry point:

```bat
start_custom_ai_test.cmd
```

It runs the same launcher with `--test`: infinite resources (topped up in the game
loop, because `all_resources` is a one-off 5000/5000 grant), `fast_build` (structures
instant, units about 17x faster — **not** zero), `food`, and forced full vision. It
builds to its own `-test` map file and never overwrites the release map, and it leaves
the user's saved `full_vision` choice alone. The cheats apply to the human
Participant; whether they reach the AI players is unverified, because the API does not
expose another player's bank.

The GUI supports:

- Logical slots P1-P14.
- Exactly one movable human slot.
- Independently enabled or empty AI slots.
- Two teams: west P1-P7 and east P8-P14.
- Per-AI race and race-specific ground-oriented build selection.
- Optional transport/detection support aircraft.
- Optional full vision for the human test view.
- One global Protoss faction preset: Standard, Aiur, Nerazim, Purifier, or Taldarim.
- Up to 7v7, subject to local SC2 performance.

Current map/game behavior:

- Rich minerals and rich gas, 50,000 resources per node.
- Worker supply cost is zero.
- Race supply ceiling is 800 (raised from 600 in v1.16.0 by user directive).
- Army production is never capped or frozen: army stock targets are the build ratio tables × 16 (deliberately unreachable), so every AI keeps producing toward the supply ceiling; campaign purchases and upgrade research run every tick behind their own bank reserves.
- Banked minerals raise scaling production-structure targets (+1 per 2,500 minerals, max +8); a Zerg AI above 3,000 minerals may add macro Hatcheries.
- The first AI expansion ignores production prerequisites but is not requested until that AI actually has 400 minerals.
- Later expansions require the build's production infrastructure for the current base count.
- Expansion placement is not delegated to the melee AI (`AIExpand`/`AISetStockExpand` are banned and verify-enforced). Each AI picks the nearest still-open candidate from the offline-solved table in `tools/build/expansion-layout.json` (57 candidates, engine-validated 5x5 placement and per-slot pathing), then expands in two stages: a move order with the town-hall allowance still closed, and — only once the builder is within 6 of the target — the allowance plus a direct `TerranBuild`/`ProtossBuild`/`ZergBuild` command 0. A candidate closes when any town hall's nearest candidate is that one (Voronoi), or when an unattributed town hall sits within 10 of its centre (§98).
- Combat aircraft are blocked; selected support aircraft may be allowed.
- Ground attacks wait for army power scaled by completed production buildings.
- The two nearest AIs can automatically support a human or AI ally that is taking critical enemy damage; only helpers whose own town hall is currently being hit are excluded (§70).
- A map-side home-defense trigger (10s cadence) sends each AI's home-area army at enemy ground forces near its town halls, and recalls the entire army when the threat outnumbers home defenders 2:1. Units on a defense/support mission are skipped by the periodic attack broadcast for the mission's duration (unit custom value 30) so attack orders no longer overwrite them (§70).
- Every infrastructure structure (tech and research buildings, including the per-race `random_ground` set) is re-ordered with an explicit `AIBuild` whenever its count drops below target, because stock requests alone are nondeterministically ignored by the melee AI (§71). An unmet-prerequisite `AIBuild` is **not** a silent no-op — issued repeatedly before the melee plan has built the structure once, it permanently stalls that player's build manager (§83 measurement: every slot with an invalid opening order produced nothing for 20 game-minutes; the v1.15.1 control was healthy). Rebuild orders therefore require both the per-player "completed once" latch (`gv_sc2team_InfraSeen`) and an any-of `REBUILD_PREREQUISITE` gate that lists every morph state of the prerequisite (SupplyDepot/SupplyDepotLowered, Hatchery/Lair/Hive, Gateway/WarpGate, CC/Orbital/PF); the `SAFE_OPENING_AIBUILD` set (Engineering Bay, Armory — §81) may skip the latch for a gated first build, never the gate (§83).
- Terran addons use native producer orders rather than `AISetStock` or `AIBuild`: every 15 seconds each AI may order one completed, idle, placement-valid facility to attach an addon, without replacing a production queue. Bio gets one Barracks Tech Lab then reactors; tank/mech plans fill eligible Factories with Tech Labs; enabled support air gets one Starport Tech Lab (§82).
- P15 wild Zerg is toggle-driven (§90–§93). ON promotes P15 to a real lobby Computer at the alpha nest and combines Blizzard melee AI with `hostile_wild_ai.galaxy`; its army supply is capped at 400, Overlord production at 448, and economy workers at eight per resource nest (§92). OFF removes the promotion/start/setup and leaves neutral-hostile P15 on the harvest-only controller. The saved configuration currently uses OFF. The fixed-team base currently has 165 preplaced P15 units across five nests; older §89–§92 measurements against 190 units/sixteen nests are historical and must not be treated as the current baseline.
- Every standard Ultralisk is globally replaced by the campaign-style Torrasque: 500 life, 3 armor, campaign model, fatal-damage cocoon, 10-second revival, and a 60-second revival cooldown.
- Zerg `roach_hydra`/`ultra_ling_bane` plans can buy Aberrations; ling-focused plans buy the global Raptor evolution after Lair tech.
- The `ultra_ling_bane` plan reinforces Blizzard's stock request with one normal `AIBuild` request for an Ultralisk Cavern after Hive completion; otherwise the melee AI can nondeterministically skip the required structure forever.
- Terran bio plans buy Medics; mech plans buy Goliaths and Predators.
- Added campaign units pay their real mineral/gas/supply costs, require their technology structure, and use per-producer build-time cooldowns. Blizzard AI still owns all ordinary production and economy.
- Aberration, Goliath, and Predator use dedicated campaign-aligned weapon/effect records rather than inheriting the parent melee body's damage.
- The four non-standard Protoss presets include retail faction skills on standard melee unit IDs. Ability costs, cooldowns, effects, and original autocast flags are copied without AI-specific rewrites.
- Aiur has Dragoon/Whirlwind; Nerazim has Blink Shield Restore, Shadow Charge/Stun, Shadow Cannon, Mind Control, and Confusion; Purifier has three-charge Blink, original Reconstruction, Chrono Beam, and Phasing Mode; Taldarim has Slayer Blink, Frenzied Overload, Target Lock, red Force Field, Mind Blast, Psionic Orb, and Sacrifice.
- Manual abilities remain manual even if Blizzard melee AI never casts them. The only necessary adaptations are wiring the retail records to the retained melee unit IDs and clearing campaign/commander progression requirements for immediately selected faction skills.

## Runtime architecture

```text
Tkinter GUI
  -> validates logical P1-P14 configuration
  -> promotes the human to SC2 runtime P1
  -> generates a per-run SC2Map
  -> launches one SC2 process and joins as the only API Participant

SC2 game
  -> runtime P1: human Participant
  -> runtime P2..Pn: Blizzard VeryHard Computer players
  -> Blizzard AI: workers, economy, construction, production, local micro
  -> generated Galaxy: team setup, fixed starts, production/economy rules,
     campaign-unit purchases, hidden command carrier, ground attack/support order execution

Python StrategyController
  -> reads controller-only full raw observations
  -> does not reveal fog of war to the human UI
  -> measures combat power and ally damage
  -> sends encoded movement orders through the hidden carrier
```

See `docs/architecture/system-overview.md` for the detailed data and control flow.

## Important current algorithms

Attack readiness:

```text
required power = clamp(14, 70, 8 + completed relevant producers * 6)
```

Flying units, workers, buildings, and support aircraft do not contribute to ground combat power. After an attack order, that AI has a 45-second strategy cooldown.

Ally support requires at least 12 damage accumulated within four seconds, an actual enemy within radius 20, and available same-team AI ground forces. The closest eligible AI sends half of its available ground army, capped at 30 units. Script control is released after 45 seconds.

The first expansion is a special case: when completed bases and total bases are both one, combat production is throttled to save the opening bank, but the town-hall cap and expansion request remain closed until current minerals reach 400. It still ignores production-building readiness. All later expansions use the adaptive production gate.
